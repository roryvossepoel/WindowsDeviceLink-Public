# WindowsDeviceLink 0.5.1-preview1

This preview focuses on observability during device-side DeviceLink association completion.

## What's new

- Visible phase logging during `Complete-WindowsDeviceLinkAssociation`.
- A 15-second heartbeat while the native `ConfigureDeviceLinkAsync` operation is still running.
- Timing telemetry for discovery, native configuration, verification, and the total completion flow.
- Progress callbacks are observational only: callback failures cannot alter the state-changing DeviceLink operation.

## Safety behavior unchanged

This release does not change the validated association safety model:

- one native configure invocation at most;
- no automatic retry;
- no automatic firmware reset;
- no cloud cleanup/deletion;
- no automatic reboot;
- firmware `4/4` plus a valid identity-matching association JWT are still required for successful completion;
- already-associated devices remain idempotent and do not run configure again.

## Live hardware validation

Validated on a physical Microsoft Surface Laptop 3 running AMD64 Windows 11.

The controlled test started from:

- local firmware state `2/4` (`DeviceLinkId` + `DeviceLinkCreationTimeUtc`);
- no association JWT;
- no tenant-side Device Association record.

A single `Initialize-WindowsDeviceLink -CompleteAssociation` run completed the full lifecycle:

```text
LocalOnly -> Register -> Preassociated -> Complete -> Associated
```

Observed completion output included:

- discovery completion after approximately 0.5 seconds;
- a visible 15-second heartbeat while native configuration was still running;
- native configuration completion after approximately 28 seconds with operation result `1`;
- post-state firmware `4/4`;
- association JWT state `Valid`;
- identity match `True`;
- final state `Associated`;
- total completion duration approximately 71 seconds.

No retry, cleanup, firmware reset, cloud deletion, or reboot occurred during the completion operation.

## Notes

The timing fields are intended as operational telemetry, not progress percentages. `TotalDurationSeconds` includes orchestration overhead beyond the three named sub-phases, such as local identity retrieval and final cloud/state verification.
